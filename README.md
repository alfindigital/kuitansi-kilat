# Kuitansi Kilat — Pembuat Kuitansi Instan

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript)](https://typescriptlang.org)

Buat kuitansi/tanda terima pembayaran dengan cepat langsung di browser. Isi form, cetak/simpan sebagai PDF. Tanpa login, tanpa backend, gratis.

---

## Fitur

- 🧾 **Buat Kuitansi** — Form sederhana, langsung jadi
- 📄 **Riwayat** — Simpan kuitansi sebelumnya di browser
- ⚙️ **Pengaturan** — Nama usaha, tanda tangan, logo
- 🖨️ **Print/PDF** — Cetak atau ekspor ke PDF
- 📱 **Mobile First** — Optimal di HP
- 🌐 **Offline** — Semua di browser, tanpa server

---

## Quick Start

```bash
git clone https://github.com/alfindigital/kuitansi-kilat.git
cd kuitansi-kilat
npm install
npm run dev
npm run build
```

---

## Stack

- TanStack Start + TypeScript 5
- Tailwind CSS + shadcn/ui
